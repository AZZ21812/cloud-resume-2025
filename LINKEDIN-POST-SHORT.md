🚀 Just completed the Cloud Resume Challenge with a modern serverless architecture!

I built a full-stack, AI-powered resume website using AWS services and production-grade DevOps practices. Here's what went into it:

**🏗️ What I Built:**

**Frontend:**
• Next.js 16 with TypeScript & Tailwind CSS
• Modern gradient design with dark mode
• Real-time visitor counter
• AI chatbot for resume Q&A

**Backend:**
• AWS Lambda (Python 3.12)
• DynamoDB for visitor tracking
• Amazon Bedrock with Claude 3 Haiku
• Serverless REST APIs

**CI/CD Pipeline:**
• GitHub Actions with 3 automated workflows
• AWS OIDC authentication (no long-lived credentials!)
• Automated testing, linting, and security scanning
• 6-10 minute deployment cycles

**Infrastructure:**
• SST (Serverless Stack) for IaC
• CloudFormation for resource management
• CloudWatch for monitoring

**📊 Stats:**
• 70+ files, 13,535+ lines of code
• 2 Lambda functions with health checks
• Automated deployments on every push
• $5-10/month estimated cost

**🎯 Key Learnings:**

1️⃣ **OIDC > Access Keys** - Modern security with temporary credentials

2️⃣ **Infrastructure as Code** - SST made serverless deployment seamless

3️⃣ **AI Integration** - Production-ready chatbot with Amazon Bedrock

4️⃣ **CI/CD Automation** - Full pipeline from commit to deployment

5️⃣ **Serverless Patterns** - Lambda, DynamoDB, and Function URLs

**🔥 Challenges Overcome:**

• Python packaging for Lambda (learned proper package structure)
• CORS configuration (Lambda Function URLs vs manual headers)
• Bedrock model access (inference profiles for Claude 3.5)
• OIDC authentication (eliminated credential management)

**🔐 Security Highlights:**
✅ GitHub Actions OIDC with AWS
✅ Least-privilege IAM policies
✅ Automated security scanning
✅ No secrets in code

**💡 Tech Stack:**
AWS Lambda | DynamoDB | Bedrock | Next.js | TypeScript | Python | SST | GitHub Actions | CloudWatch | IAM

**⚡ Performance:**
• Counter API: ~200ms
• Chatbot: ~2-4s (LLM inference)
• CI Pipeline: 3-5 mins
• Backend Deploy: 2-3 mins

The Cloud Resume Challenge isn't just about hosting a resume - it's about demonstrating real-world cloud engineering skills. This project showcases full-stack development, DevOps expertise, AWS proficiency, and modern security practices.
